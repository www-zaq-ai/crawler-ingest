# opendataloader-pdf runs a bundled JAR and needs a JRE 11+. Deployment images
# ship no system Java, so jdk4py provides one as a pip wheel (~94 MB) and
# pdf_to_md.py points the loader at it. Drop jdk4py only if every runtime
# environment is guaranteed to have its own JRE.
